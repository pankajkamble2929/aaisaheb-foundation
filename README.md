# 🌸 AaiSaheb Foundation

A modern NGO website built with **Next.js, TypeScript, Tailwind CSS and Lucide Icons**.

## 🛠️ Tech Stack

- ⚡ Next.js
- 🔷 TypeScript
- 🎨 Tailwind CSS
- ✨ Lucide React
- 🖼️ Next/Image
- 📱 Responsive Design

## 📄 Pages

- 🏠 Home
- 👥 About
  - Mission & Vision
- 📅 Our Events
  - Year-wise event archive
  - Event galleries
- 📞 Contact
- 🔒 Privacy Policy
- 📋 Terms & Conditions
- ⚠️ Disclaimer

## 📸 Events & Gallery

- 📆 Events displayed year-wise
- 🆕 Latest events shown first
- 🖼️ Multiple photos for each event
- 🔗 Individual event galleries
- 🧭 Event-to-gallery navigation using IDs
- 📂 Gallery organised event-wise

## 🚀 Run Locally

- npm install
- npm run dev
